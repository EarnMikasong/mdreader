# mdreader

一个面向 Windows 的轻量 Markdown 阅读与编辑工具，适合处理笔记、项目文档和 AI 生成的 Markdown 报告。

当前版本：**v1.2.0**

无需安装 Python，下载后即可使用；代码高亮、数学公式、Mermaid 图表等前端资源均已内置，本地文档可以断网阅读（网络图片仍需联网加载）。

## 快速上手

1. 前往 [Releases](https://github.com/EarnMikasong/mdreader/releases/latest) 下载推荐的 `mdreader-windows-x64.zip`，并解压到固定位置。只需要基本阅读功能时，也可以只下载 `mdreader.exe`。
2. 双击解压后的 `mdreader.exe`，程序会自动在默认浏览器中打开阅读页面。
3. 点击左上角的 **📁** 选择一个文档文件夹，或点击 **📄** 打开单个 Markdown 文件。
4. 在左侧文件树中切换文档；需要修改时点击顶部 **编辑**（或直接点正文），在保留排版的“所见编辑”中修改，按 `Ctrl+S` 保存。
5. 顶部工具栏可插入标题、加粗/斜体/下划线、链接、列表、引用、待办、代码块、表格、分割线和本地图片；点击 **源码**可精确编辑 Markdown 原文。
6. 阅读时选中一段文字，点击浮出的“添加批注”（或右上角 💬）即可写侧边批注；批注单独保存在本机，不会改动原 Markdown。
7. 使用结束后，双击同目录中的 `退出.bat` 结束后台服务。

> Windows 首次运行时可能显示 SmartScreen 提示。这是因为 EXE 暂未购买代码签名证书；请确认文件来自本仓库的 Release 页面，再点击“更多信息 → 仍要运行”。

当前 Release 提供 Windows x64 版本。

## 常用打开方式

| 使用场景 | 操作 |
| --- | --- |
| 打开阅读器 | 双击 `mdreader.exe` |
| 直接打开一个文档 | 将 `.md` 文件拖到 `mdreader.exe` 上，或在解压目录运行 `.\mdreader.exe "D:\我的文档\笔记.md"` |
| 打开整个文档库 | 在解压目录运行 `.\mdreader.exe "D:\我的笔记"` |
| 设为 Markdown 打开方式 | 使用 ZIP 推荐版，运行 `设为md打开方式.bat` |
| 取消文件关联 | 运行 `取消关联.bat` |
| 退出后台实例 | 运行 `退出.bat`；单 EXE 用户也可在任务管理器中结束 `mdreader.exe` |

同一时间只会运行一个 mdreader 服务。再次打开其他 Markdown 文件时，文件会交给已有实例，并在同一个浏览器页面中显示。关闭浏览器页面不会结束后台服务，需要运行 `退出.bat` 或在任务管理器中结束进程。

## 主要功能

- Typora 风格排版，支持标题、表格、任务清单、脚注和 YAML front matter
- 代码高亮与一键复制，支持 KaTeX 数学公式和 Mermaid 图表
- 文件树、大纲、按日期分组的最近查看、文件名筛选和全文搜索；最近记录可单独移除，不会删除原文件
- 点击渲染后的正文即可直接编辑文字与排版；所见编辑工具栏提供标题、格式、链接、列表、待办、引用、代码块、表格、分割线和本地图片
- 所见编辑与 Markdown 源码编辑可随时切换，支持 `Ctrl+S` 保存和源码 Tab 缩进
- 公式、Mermaid、脚注等复杂结构在所见模式中受保护，双击即可切到源码精确修改
- 选中正文即可添加侧边批注；批注有高亮、已解决与删除状态，保存在本机工作层而不写进 Markdown
- 阅读时自动刷新外部修改；编辑时进行修改冲突检测，避免静默覆盖
- 支持本地相对路径图片、绝对路径图片和网络图片
- 亮色、暗色、跟随系统主题，以及多种阅读背景色
- 字号、正文宽度、侧栏宽度和配色自动记忆
- 使用 `Ctrl+P` 打印或导出 PDF

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开文件夹 |
| `Ctrl+Shift+O` | 打开单个文件 |
| `Ctrl+F` | 在当前文档中查找 |
| `Ctrl+E` | 切换所见编辑 / Markdown 源码编辑 |
| `Ctrl+S` | 保存当前编辑（继续留在编辑状态） |
| `Ctrl+Alt+M` | 对选中的文字添加侧边批注 |
| `Ctrl+K` | 快速跳转 |
| `Ctrl+B` | 显示或隐藏侧栏 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 调整或重置字号 |
| `Alt+←` / `Alt+→` | 后退或前进 |
| `Ctrl+P` | 打印或导出 PDF |

## 从源码运行

mdreader 后端只使用 Python 3 标准库，无需安装第三方运行依赖：

```powershell
python mdreader.py
```

也可以在启动时直接指定文件或文件夹：

```powershell
python mdreader.py "README.md"
python mdreader.py "D:\我的笔记"
```

更完整的功能说明、文件结构和打包命令见 [`说明.md`](./说明.md)。

## 隐私与安全

mdreader 仅监听本机地址 `127.0.0.1:7333`，不会把文档上传到云端。读盘接口还需要用户目录下生成的私有令牌，其他网页无法直接读取你的本地文件。
