# 小工具集

日常自用的小工具合集，一个文件夹一个工具，互相独立。

## 工具列表

| 工具 | 说明 |
|------|------|
| [md-reader](./md-reader/) | 轻量 Markdown 阅读器（替代 Typora 的阅读端）。单文件 exe 双击即用，支持代码高亮、KaTeX 公式、Mermaid、脚注、背景调色、导出 PDF。详见其目录下的 `说明.md` |

## 仓库约定

- **一个工具一个文件夹**，各自带一份 `说明.md`，互不依赖
- 新增工具时在上面的表格加一行
- 提交信息用 `工具名: 做了什么` 的格式（仓库级改动用 `repo:` 前缀）
- 构建产物、exe 不入库（根 `.gitignore` 已统一忽略）；某个工具**特有**的忽略规则，放它自己文件夹下的 `.gitignore`
