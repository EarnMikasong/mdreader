# mdreader —— 轻量 Markdown 阅读器

轻量 Markdown **阅读与编辑**工具。已打包成单文件 `mdreader.exe`，**双击即用，不需要装 Python**；所有前端库离线内置，断网可用。（也可以用源码方式跑：Python 3 标准库，零依赖。）

## 怎么用

| 方式 | 操作 |
|------|------|
| 直接启动 | 双击 `mdreader.exe` 或 `启动.bat`，在界面里选文件夹或文件 |
| 打开某个文件 | `mdreader.exe 文档.md`（或 `python mdreader.py 文档.md`） |
| 打开文档库 | `mdreader.exe D:\笔记`（左侧出现整个目录树） |
| 编辑并保存 | 直接点击排版后的正文进行所见编辑，按 `Ctrl+S` 保存；点击顶部“完成”返回阅读视图 |
| 编辑 Markdown 原文 | 点击顶部“源码”；再次点击“所见”返回排版编辑 |
| 双击 .md 就打开 | 运行一次 `设为md打开方式.bat`（优先注册 exe；只写当前用户注册表，不要管理员；`取消关联.bat` 可撤销） |
| 退出后台实例 | 双击 `退出.bat`（用右键菜单打开时没有窗口，用它来关） |

> 给别人用：把整个 `md-reader` 文件夹拷过去（或只拷 `mdreader.exe` + 三个 bat）即可，对方无需任何环境。首次运行如被 SmartScreen 拦截，点「更多信息 → 仍要运行」。

同一时间只会有一个服务进程：再打开别的 md 文件会交给已运行的实例，在同一个页面里切换。

## 功能

- Typora 风格排版：标题、引用、表格、任务清单、脚注、YAML front matter
- 代码高亮（highlight.js）+ 一键复制、行内/块级数学公式（KaTeX）、Mermaid 图表
- 左侧文件树 / 大纲（滚动跟随高亮）/ 最近打开；输入框筛选文件名，回车全文搜索
- 点击渲染后的正文直接进行所见编辑，标题、粗体、斜体和列表排版不会消失
- 所见编辑与 Markdown 源码编辑可以随时切换，支持保存、源码 Tab 缩进和未保存提醒
- 公式、Mermaid、脚注等复杂结构在所见模式中受保护，可双击切换到源码精确修改
- 阅读时检测到外部修改会自动重新载入；编辑时会阻止覆盖磁盘上的新版本
- 图片：相对路径、绝对路径、`file:///`、网络图都支持，网图自动绕过防盗链
- 亮色 / 暗色 / 跟随系统三档主题；🎨 背景调色（羊皮纸 / 护眼绿 / 淡蓝 / 浅灰 / 自定义颜色）
- 字号、页宽、侧栏宽度、配色全部记忆；`Ctrl+P` 走浏览器打印导出 PDF

## 快捷键

`Ctrl+E` 切换所见/源码编辑 · `Ctrl+S` 保存 · `Ctrl+F` 文内查找（`F3` 下一个）· `Ctrl+B` 侧栏 · `Ctrl+O` 打开文件夹 · `Ctrl+Shift+O` 打开文件 · `Ctrl+K` 快速跳转 · `Ctrl+=` / `Ctrl+-` / `Ctrl+0` 字号 · `Alt+←` / `Alt+→` 前进后退 · `Esc` 关闭浮层

## 安全性

服务只监听 `127.0.0.1:7333`，所有读盘接口都要求 `~/.mdreader/token` 里的私有令牌，其他网页拿不到你的文件。

## 文件说明

```
mdreader.exe     打包好的单文件程序（PyInstaller），双击即用
mdreader.py      后端源码（纯标准库，约 400 行）
app/             前端页面 + 离线依赖（marked / highlight.js / KaTeX / Mermaid）
示例文档/         功能演示用的样例，第一次可以拿它试试
_test_render.py  开发自检脚本（需 pip install playwright），改代码后跑一遍验证渲染
```

> 注意：`mdreader.exe` 不在 git 仓库里（11 MB 二进制不适合进版本历史）。
> 从仓库 clone 下来的话，要么去 Release 页下载现成的 exe，要么按下面命令自己打一个。

改了源码后重新打包：

```
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --name mdreader --icon mdreader.ico --add-data "app;app" mdreader.py
```
